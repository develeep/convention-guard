# 4.0.0 진행 기록

설계 문서: [design-4.0.md](design-4.0.md)

## 현재 지점

- 단계: **단계 2 완료, 단계 보고 후 승인 대기.** 커밋 안 함(요청 시).
- 설계 승인 완료 (2026-10-01, D1~D7 모두 권장안).
- 단계 1 승인·커밋 `206c20a` (푸시 안 함).

## 단계 2 계획

- `lib/decide.py` (순수): 상태(dict, 입력을 고치지 않음) × Observation × cfg → (다음 상태, Action, 로그 이벤트). `cycle.py` 의 분류를 흡수.
- 스캔 여부는 `needs_scan(state, request, cfg)` (순수) 로 셸이 먼저 묻는다 — 질문 턴·이어진 Stop 에서 스캔 비용을 내지 않던 3.x 동작 유지.
- I/O 는 셸(`lib/stop.py`): 상태 읽기·쓰기, 스캔+자동 수정, 트리아지, 배치 판정 읽기, 기각 로드, 배치 저장, 로그, 출력 렌더.
- 배치 id 는 셸이 미리 만든 토큰(Observation 에 넣음) → decide 가 상태에 참조를 바로 적는다. `review_batch.id` 를 TEXT 로.
- `hooks.py` 는 수집 정책만 남긴다 (단계 3 에서 원장으로 대체).

## 단계 2 결과

- `lib/decide.py` (순수, 임포트는 copy·batch·candidate 뿐 — `test_decide.case_pure` 가 강제), `lib/batch.py` (배치 계획·참조, 순수), `lib/stop.py` (셸), `hooks.py` 는 수집만, `cycle.py` 삭제(분류는 decide 로).
- 3.x 전이를 그대로 옮기는 방식: 3.x 가 `ctx.save()` 하던 지점마다 상태 스냅샷 → Decision.state 는 "3.x 가 마지막으로 저장했을 상태". 그래서 `test_hook_cycle.py` 등 종단 테스트가 수정 없이 통과.
- 행동(Action)은 Silent / Notice(word, parts, level) / ConfigError / Block(form, args). 문자열은 `stop.render` → `report.*`.
- 배치 id 는 셸이 미리 만든 16자 hex 토큰(`review_batch.id` TEXT, 스키마 2).
- 알림 함수(`unchecked_note` 등)는 `report.py` 로, 알림 붙이기(`with_notes`, `with_autofix_note`)는 `stop.py` 로.
- `tests/unit/test_decide.py`: 조용한 경로, 열기, R4(요청마다 상한), 검증(고쳐짐/남음/상한/새로 생김/기각), R3(미표시는 통과 아님), R17(린터 미확인), 포기된 사이클, 의미 판정(요청·미실행·VALID·VIOLATION·report 모드), 순수성.
- 측정(같은 실행, 단계 1 커밋 대비): Stop 143.7 → 117.9ms (잡음 큼), 수집 훅 Post 78.3 → 38.1ms — `collect.py` 가 더는 파이프라인 전체를 임포트하지 않기 때문.

## 단계 1 에서 둔 가정

- `structure/native/` 의 Go 등 비대상 언어 정의는 단계 4 에서 계층과 함께 지운다 (지금 지우면 곧 삭제할 테스트를 고쳐야 함).
- 0.x 설정 키·레이아웃 감지는 지웠다. 그런 키는 일반 "알 수 없는 설정 (무시)" warn 이 된다.
- 테스트 러너(`run_all.py`)가 실행마다 임시 `CLAUDE_PLUGIN_DATA` 를 준다 — 프로세스 안에서 규칙을 읽는 스위트가 개발자의 실제 데이터 디렉터리에 DB 를 만들지 않게.
- Python 스택·규칙이 아직 없다. 단계 4 에서 Python 구조 엔진을 시험할 최소 규칙(디버그 출력, 빈 except)과 `python` 스택을 더할지 단계 4 보고에 제안한다.

## 확인한 외부 사실 (2026-10-01)

- 훅 공통 입력에 `session_id`, `prompt_id`(v2.1.196+), `transcript_path`, `cwd`, `permission_mode`, `hook_event_name`. Pre/Post 에 `tool_use_id`. `PostToolUseFailure`(도구 실패 후), `PostToolBatch` 이벤트가 있다. command 훅 `async: true` 는 백그라운드 실행. 기본 타임아웃 600초. `systemMessage` 는 사용자에게 보이는 경고. (code.claude.com/docs/en/hooks)
- `${CLAUDE_PLUGIN_DATA}` = `~/.claude/plugins/data/<id>/`, 업데이트 후에도 유지, 훅 환경 변수로 전달.
- PyPI: tree-sitter 0.25.2(cp310–314, abi3 아님), javascript 0.25.0·php 0.24.1·python 0.25.0(cp310-abi3, ABI 15), typescript 0.23.2(cp39-abi3, ABI 14). core 0.25+ 는 ABI 13–15. 0.23.2 core 는 cp314 휠 없음. musl aarch64 휠 없음. Blade 문법 패키지 없음. PyPI JSON `digests.sha256` 있음. 휠 목록: 스크래치 `pypi/tree_sitter_wheel_manifest.json` (세션 임시 — 단계 4 에서 `engine.py lock` 으로 다시 만든다).
- WSL 에 `/root/.local/bin/uv`, `/root/.local/bin/claude` 가 있다 (PATH 에 없을 수 있음).
