# 검사 대상은 팀 컨벤션으로 한정한다

convention-guard 는 팀이 정한 코드 작성 규칙(계층, 이름, 금지 API 등)만 다루고, 보안 취약점과 버그 탐지는 다루지 않는다. Sonar·Semgrep·Copilot 은 이미 타입·빌드 정보를 갖춘 보안 분석을 에이전트 훅으로 돌리고 에이전트가 스스로 고치게 하지만([조사](../research/convention-review-systems.md)), 파일 단위 구문 트리만 보는 이 도구는 그 정밀도를 따라갈 수 없다. 반대로 "팀 규칙을 에이전트 줄에만 강제"하는 것은 그 도구들에 없다.

## Consequences

- `security` 프리셋은 남기되 `presets: auto` 기본값에서 뺀다. 쓰려면 명시해야 켜지고, 문서는 보안 검사를 전용 도구에 맡기라고 안내한다. 이미 켠 팀은 깨지지 않는다.
- 새 core 규칙이 보안·버그 탐지라면 받지 않는다.
