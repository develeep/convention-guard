# 트리아지 라벨

스킬들은 트리아지 역할 다섯 가지로 말한다. 이 파일은 그 역할을 이 레포 이슈 트래커의 실제 라벨 문자열에 대응시킨다.

| mattpocock/skills 의 라벨 | 우리 트래커의 라벨 | 뜻                                   |
| ------------------------- | ------------------ | ------------------------------------ |
| `needs-triage`            | `needs-triage`     | 메인테이너가 평가해야 함             |
| `needs-info`              | `needs-info`       | 보고자에게 추가 정보를 기다리는 중   |
| `ready-for-agent`         | `ready-for-agent`  | 명세가 끝나 AFK 에이전트가 맡을 수 있음 |
| `ready-for-human`         | `ready-for-human`  | 사람이 구현해야 함                   |
| `wontfix`                 | `wontfix`          | 처리하지 않음                        |

스킬이 역할을 말하면(예: "AFK 준비 트리아지 라벨을 붙여라") 이 표에서 대응하는 라벨 문자열을 쓴다.

실제로 쓰는 이름이 다르면 오른쪽 열을 고친다.
